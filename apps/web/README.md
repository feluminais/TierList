# web

The Next.js app: the landing page, the editor, and the public page a share code resolves to.

## Routes

| Route | Rendering | What it is |
|---|---|---|
| `/` | static | Landing page. |
| `/editor` | client only | The Skia board and its chrome. |
| `/l/[code]` | server, revalidated | A shared list as plain HTML. Loads no canvas. |

## Running it

```bash
pnpm --filter web dev
```

Skia is confirmed against a production build rather than the dev server:

```bash
pnpm --filter web build && pnpm --filter web start
```

`postinstall` copies `canvaskit.wasm` and the board font into `public/`. Both are gitignored and
regenerated by `copy-assets.js`, so an install run with `--ignore-scripts` serves 404s for them.

## Connecting the API

`NEXT_PUBLIC_API_URL` points the editor and the public page at `services/api`. Unset means the
editor holds the document on the page and saves nothing, which is the default for local work.

```bash
NEXT_PUBLIC_API_URL=http://localhost:8788 pnpm --filter web dev
```

`services/api/scratch-dev-api.ts` serves that port over an in-memory database.

## Tests

```bash
pnpm --filter web test
```

They cover the hooks and the pure parts of the DOM chrome. The canvas has no component tests;
changes to it are confirmed in a browser.
